把收纳盒擦成一块玻璃

常驻悬浮的快捷收纳面板，重构为玻璃拟态基座：半透明面板 + 背景模糊 + 发光描边。 分组、搜索、多选批量、排序整理、片段预览、设置与更新等全部界面在本原型里可点、可拖、可改， 尺寸沿用主进程默认窗口 400 × 580，不改动任何交互契约。

01 · 主界面

一块会呼吸的悬浮面板

标题栏 → 搜索/排序 → 分组胶囊 → 卡片网格 → Dock，五段纵向节奏与现有渲染层一一对应。 下面这块窗口是活的：切分组、搜关键词、Ctrl 点选、进整理模式拖顺序、开设置改不透明度，都能真的动。

交互原型 · 与主进程 IPC 契约一致（此处为内存数据）

重构后保留的硬契约

换皮肤不换手感：以下行为在重构前后必须逐条一致，原型已按此实现。

  • 固定项恒置顶：任何排序方式下都不被推翻，那是「钉住」本身的含义。
  • 一次批量 = 一次 IPC + 一次落盘 + 一次状态推送，界面只 setState 一次。
  • 批量只作用于 selectedIds ∩ visible：搜索过滤掉的项不会被误操作。
  • 右键清空多选，单选走右键菜单；普通左键不再顺手选中。
  • 不透明度下限 78%：常驻悬浮窗，再透字就压在壁纸上读不清。
  • 整理模式内卡片拖拽只改顺序，禁用拖出到资源管理器；固定项不参与。
  • 只存路径，不搬文件：移除仅删记录，路径失效标红而非静默消失。

02 · 状态总览

每一种界面状态都画到了

常态只占界面的一半工作量，剩下的是空、找不到、选中、排队、失效、拖拽、升级。 以下快照与主界面共用同一套组件样式，仅状态不同。

03 · 设置与更新

面板内浮层，不另开窗口

设置以整屏浮层覆盖在面板内，保持「一切都在盒子里」的连续性。四套主题在重构后收敛为 同一玻璃基座上的强调色重映射：底色、描边、文字全部由 token 混出，夜墨为暗色档。 更新走 GitHub Release，检查在启动 6 秒后、之后每 6 小时一次；便携版与开发版不支持应用内更新。

04 · Token 契约

页面里没有一个自造字面量

所有颜色、字号、间距、圆角、阴影、动效时长都取自 Glassmorphism 的 :root；派生层只用 color-mix() 与 calc() 组合既有 token， 不新增色值、不新增字号档位。

05 · 诚实边界

这些不做，也不是 bug

重构只动视觉层，产品边界与现有版本保持一致，原型如实呈现而不是藏起来。

只存路径

收纳盒不搬动、不复制任何文件。原文件被删或被移动，卡片转为「路径失效」的红色虚线态，仍可移除记录。

图标尽力而为

.lnk 需读 (IconLocation, index)，PE 解析只读文件头与 .rsrc； 取不到时按自绘矢量图兜底。图标缓存随进程结束而清空。

更新有前提

便携版与未打包版不支持应用内更新，只能跳发布页；macOS 未签名包首次启动会有 Gatekeeper 提示。

数据只在本机

配置落在 %APPDATA%/desk-box/desk-box.json，防抖后原子写入；解析失败会改名保留为 .broken-<时间戳>，不上传任何服务器。

托盘与登录项

托盘图标保持固定中性色，不随主题变化；便携版下「开机自启」可能静默失败，界面不谎报成功。

透明窗兜底

Windows 的 ready-to-show 对透明窗不可靠，因此保留三重显示兜底； 不透明度低于 78% 会被夹回下限，滑块也走同样的夹取函数。
